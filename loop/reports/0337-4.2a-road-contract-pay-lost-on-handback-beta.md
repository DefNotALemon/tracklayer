# 0337 — 4.2a road contract: pay earned before hand-back / strike-off never reaches Monday's statement (G4) — main @ 9cbbbe4
Scenario: tools/playtest/scenarios/x4_con_weekpay_quit_beta.mjs (new). Shots: none (state test).

Part tested: the kommune road contracts' weekly statement, after v24's fix for drives and lots (0325 #1 / 0328).

## Findings
1. [BUG] Same class as 0325 #1, left unfixed on roads. Sign a road, earn $300 (c.wk = 300, 800 m), hand it back (`TLXPL.con.quit`), run Monday: `conLast` has no row for it (empty). Control in the same run: a road kept to Monday with $150 lists `{road:"Gamvik road", pay:150, m:400}`. Cause: `conQuit` does `delete s.con[id]` and `conMonday` sums only `s.con`; `wkKeep`/`wkTake` were added for drv/lot only. The cash was already paid at the stretch, so only the statement is wrong, but the player sees the week's pay vanish.
2. [BUG] Same loss when the road is struck off on the third warning (`conStrike` deletes `s.con[r.id]`): road with $200 earned and 2 warnings, forced a late stretch via step → contract gone, Monday shows nothing for it.
   Suggested fix: keep `conWk/conWkM` carry-over on state (wkKeep for "con" in `conQuit` and `conStrike`'s third-warning branch and the `!r` delete in conStep), add it as a row (or into one "Roads" line) in `conMonday`, tidy it in `conTidy`. Note `conMonday` returns early on no contracts, so it must run the carry even with `ids` empty. Also a driver's `s.pdr[id].wkN` count (dn) goes with it.
