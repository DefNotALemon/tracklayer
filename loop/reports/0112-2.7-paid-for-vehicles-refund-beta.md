# 0112: 2.7 paid-for vehicles count as owned + stuck-order refund: beta test (main 5ae6fda, v186)

Focus: beta fix 0110 (the newest landing). Reran `x2_vehheld.mjs` and `x2_vehmktbreak.mjs`, then wrote `x2_vehheld_break.mjs` (committed) to break the refund. No BLOCKER, no BUG in the fix itself; one flaky assert in the fix's own scenario (POLISH). No stills (logic only).

## What held
- `x2_vehmktbreak.mjs`: 9/9 (trailer row locks, paid-for trailer handed over, held pickup survives reload), page errors none.
- `x2_vehheld.mjs`: 3 of 4 runs fully green (trailer row reads "Paid for", buyHaul/buy refuse with no money taken, refunds +3000).
- New `x2_vehheld_break.mjs` 12/12: a stuck trailer order planted in a save refunds exactly +500 in game, survives a reload with cash 10500 and trailer kept, and a second reload does NOT refund again (api.save runs after the refund). Mixed case (3 trucks owned + stuck pickup + collectable trailer): only the pickup is refunded (+2500 exact), the trailer order is untouched and still handed over at the yard.

## Findings
1. POLISH (test flake): in 1 of 4 first runs of `x2_vehheld.mjs`, section B failed four asserts: "1 held + 0 owned: buying a truck at the garage still works" and the chain after it ("2nd still sells (owned 3)", rows lock, 3rd refused). The following 6+3 reruns and a debug copy with per-fail state dumps all passed, so it is not reproduced. The failing run was the first cold start after a pause; suspect `TLXV.buy` returning early (`forecourtSpot` null or a toast guard) when timing differs, with a fixed `sleep(200)`. Suggested: have the scenario print `TOASTQ` on a B failure, and `waitUntil` on owned length instead of sleeping 200 ms. The game logic looks fine.
2. POLISH (carry-over, unchanged): `MKTV.blocked` refund fires from `tick` only every 2 s and only when the garage code runs; not tested when the player is inside an interior or on the tablet (INT.on). Not tested: seller yard without a clear spot, phone layout of the Trucks tab "waiting in..." line.

Scenario: `tools/playtest/scenarios/x2_vehheld_break.mjs`.
